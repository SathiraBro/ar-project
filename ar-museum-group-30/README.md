# Group 30 – AR Mini Museum

## Project Description

An augmented reality mini museum developed using
A-Frame and AR.js.

Visitors can explore a miniature museum using a
Hiro marker and a camera-enabled device.

## Technologies Used

- HTML
- CSS
- JavaScript
- A-Frame
- AR.js
- glTF / GLB 3D models

## Features

- Hiro marker-based augmented reality
- 3D museum objects
- Animated museum artifacts
- Interactive 3D objects
- Marker detection status banner
